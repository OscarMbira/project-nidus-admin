# Module documentation

Add one Markdown guide per major workflow in this folder. CI syncs `*.md` to Supabase Storage on push to `main`.

## Conventions for new modules

- List guides in the table below as you add them.
- Register guides in `admin.documentation_guides` via seed SQL when adding a new guide file.
- **Create/edit forms:** wire `useUnsavedChangesGuard(isDirty)` from `@nidus-admin/shared` — see `CLAUDE.md` Documentation & Testing §6.
