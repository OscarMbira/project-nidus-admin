**Status:** Complete

## Overview

Adds a **Payment Config** group under **Subscription & Billing** in the admin sidebar. Covers **six configurable entities** — gateways, payment methods, method routing, promo codes, retry rules, and settlement accounts — all with full CRUD.

### Launch Gateway Strategy (3 gateways)

| Priority | Gateway | Role | Market Covered |
|---|---|---|---|
| **1 — Default** | PayNow (paynow.co.zw) | Local Zimbabwe mobile money | EcoCash, OneMoney, Telecash, ZimSwitch, ZIPIT |
| **2 — Regional** | Flutterwave | Africa-wide + M-Pesa + MTN MoMo | 30+ African countries, international cards |
| **3 — International** | Paddle | Global SaaS (US, UK, Europe, Middle East, Asia cards) | Cards, PayPal, Apple Pay, Google Pay — full tax/VAT compliance as Merchant of Record |

**All subscriptions are billed in USD.** ZWL is not used for subscription billing due to exchange rate volatility.

**Deferred gateways (post-launch, architecture already supports them):**
- Razorpay — add when India becomes an active market (UPI/Netbanking coverage)
- dLocal — add for SE Asia, South Asia, Egypt (GoPay, GCash, bKash, Fawry)
- China gateway — deliberate deferral (WeChat Pay / Alipay — regulatory complexity)

**Dropped from original proposal:** Stripe (not accessible from Zimbabwe), PayPal (withdrawal blocked by RBZ), Braintree, Square.

### 3. Method Routing (`/subscriptions/payment-method-routing`)

**Purpose:** The critical layer between gateways and customers. Maps user-visible payment choices to backend gateways, with country/region scoping, priority, and fallback. Users see payment method names (e.g. "EcoCash") — never gateway names.

**How it works at checkout:**
1. Customer's country is read from their billing profile
2. System queries this routing table for methods matching their country or region
3. Customer sees only the available methods for their location
4. On selection the system routes silently to the correct gateway

**List page columns:**
Display Label, Method Type, Primary Gateway, Fallback Gateway, Region Scope, Countries, Status, Order, Actions

**Fields:**

| Field | Type | Notes |
|---|---|---|
| Display Label | text | What the customer sees — e.g. "EcoCash", "M-Pesa", "Pay by Card" |
| Method Type | FK select | From payment_methods |
| Primary Gateway | FK select | First choice gateway |
| Fallback Gateway | FK select (nullable) | Used if primary gateway is down or declines |
| Region Scope | select | local / africa / global |
| Supported Countries | multi-select | ISO country codes — null means all countries in region |
| Display Order | integer | Order shown at checkout |
| Enabled | toggle | |

**Pre-configured routing rules (from seed data):**

| Display Label | Method | Primary | Fallback | Scope | Countries |
|---|---|---|---|---|---|
| EcoCash | ecocash | PayNow | Flutterwave | local | ZW |
| OneMoney | onemoney | PayNow | — | local | ZW |
| Telecash | telecash | PayNow | — | local | ZW |
| ZimSwitch | zimswitch | PayNow | — | local | ZW |
| ZIPIT Bank Transfer | zipit | PayNow | — | local | ZW |

| Google Pay | google_pay | Paddle | — | global | — |

**Actions:** Add Route, Edit inline, Toggle Enabled, Reorder (drag), Delete

---

### 5. Retry Rules (`/subscriptions/payment-retry-rules`)

**Purpose:** Configure automated retry schedules for failed payments. Critical for PayNow since it has no native recurring billing — the COB/batch system drives retries using these rules.

**List page:** Table with rule name, gateway scope, max attempts, status.

**Fields:**

| Field | Type | Notes |
|---|---|---|
| Rule Name | text | |
| Gateway | FK select (nullable) | null = applies to all gateways |
| Failure Code Scope | text | null = all failures; or specific e.g. "insufficient_funds" |
| Retry Schedule | dynamic rows | Max 6 rows |
| Max Attempts | integer | Derived from schedule row count |
| Active | toggle | |

**Retry schedule row columns:** Attempt #, Delay After Previous Failure (hours), Notify Customer (toggle)

**Default rule seeded:** 3 attempts — 1h, 24h, 72h — all gateways, all failure types, customer notified on each

**Actions:** Create Rule, Edit, Toggle Active, Delete

---

**Purpose:** Record the bank/merchant accounts where each gateway settles funds. For audit, accounting, and reconciliation.

**List page columns:**
Account Name, Bank, Currency, Account (masked), Gateway, Default, Status, Actions

**Fields:**

| Field | Type | Notes |
|---|---|---|
| Account Name | text | Internal label |
| Linked Gateway | FK select (nullable) | Which gateway settles here |
| Bank Name | text | |
| Account Number | text | Stored masked — last 4 digits visible |
| Routing / SWIFT Code | text | Stored masked |
| Currency | select | From admin.currencies |
| Account Type | select | checking / savings / merchant |
| Is Default | toggle | One default per currency |
| Active | toggle | |
| Notes | textarea | |

**Actions:** Create, Edit, Toggle Active, Set as Default (per currency), Delete (only if inactive)

## SQL Plan

### `v46_payment_configuration.sql`

**Tables (all in `admin` schema):**

```sql
admin.payment_gateways
  id UUID PK,
  name TEXT NOT NULL,
  provider_key TEXT NOT NULL CHECK (provider_key IN ('paynow','flutterwave','paddle','razorpay','dlocal')),
  display_name TEXT NOT NULL,
  environment TEXT NOT NULL CHECK (environment IN ('sandbox','production')),
  api_key_masked TEXT,
  api_secret_hash TEXT,           -- SHA-256 hash, never returned
  webhook_secret_hash TEXT,       -- SHA-256 hash, never returned
  is_active BOOLEAN DEFAULT FALSE,
  is_default BOOLEAN DEFAULT FALSE,
  metadata JSONB DEFAULT '{}',
  notes TEXT,
  created_by UUID REFERENCES admin.admin_users(id),
  updated_by UUID REFERENCES admin.admin_users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()

admin.payment_methods
  id UUID PK,
  gateway_id UUID NOT NULL REFERENCES admin.payment_gateways(id),
  method_type TEXT NOT NULL,
  display_name TEXT NOT NULL,
  supported_currencies TEXT[] NOT NULL DEFAULT '{USD}',
  min_amount NUMERIC(12,2) DEFAULT 0,
  max_amount NUMERIC(12,2),
  fee_type TEXT DEFAULT 'none' CHECK (fee_type IN ('none','fixed','percentage')),
  fee_value NUMERIC(8,4) DEFAULT 0,
  display_order INTEGER DEFAULT 0,
  is_enabled BOOLEAN DEFAULT TRUE,
  created_by UUID REFERENCES admin.admin_users(id),
  updated_by UUID REFERENCES admin.admin_users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()

admin.payment_method_routing
  id UUID PK,
  display_label TEXT NOT NULL,
  payment_method_id UUID NOT NULL REFERENCES admin.payment_methods(id),
  primary_gateway_id UUID NOT NULL REFERENCES admin.payment_gateways(id),
  fallback_gateway_id UUID REFERENCES admin.payment_gateways(id),
  region_scope TEXT NOT NULL CHECK (region_scope IN ('local','africa','global')),
  supported_countries TEXT[],     -- NULL = all countries in region
  display_order INTEGER DEFAULT 0,
  is_enabled BOOLEAN DEFAULT TRUE,
  created_by UUID REFERENCES admin.admin_users(id),
  updated_by UUID REFERENCES admin.admin_users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()

admin.promo_codes
  id UUID PK,
  code TEXT NOT NULL UNIQUE CHECK (upper(code) = code),
  name TEXT NOT NULL,
  description TEXT,
  discount_type TEXT NOT NULL CHECK (discount_type IN ('percentage','fixed_amount')),
  discount_value NUMERIC(10,2) NOT NULL CHECK (discount_value > 0),
  currency_code VARCHAR(3) REFERENCES admin.currencies(currency_code),
  max_uses INTEGER,               -- NULL = unlimited
  current_uses INTEGER DEFAULT 0,
  applicable_plan_keys TEXT[],    -- NULL = all plans
  valid_from TIMESTAMPTZ,
  valid_until TIMESTAMPTZ,
  is_active BOOLEAN DEFAULT TRUE,
  created_by UUID REFERENCES admin.admin_users(id),
  updated_by UUID REFERENCES admin.admin_users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()

admin.payment_retry_rules
  id UUID PK,
  rule_name TEXT NOT NULL,
  gateway_id UUID REFERENCES admin.payment_gateways(id),  -- NULL = all gateways
  failure_code TEXT,              -- NULL = all failure types
  retry_schedule JSONB NOT NULL,  -- [{attempt, delay_hours, notify_customer}]
  max_attempts INTEGER NOT NULL,
  is_active BOOLEAN DEFAULT TRUE,
  created_by UUID REFERENCES admin.admin_users(id),
  updated_by UUID REFERENCES admin.admin_users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()

admin.settlement_accounts
  id UUID PK,
  account_name TEXT NOT NULL,
  gateway_id UUID REFERENCES admin.payment_gateways(id),
  bank_name TEXT NOT NULL,
  account_number_masked TEXT,     -- e.g. "****1234"
  routing_code_masked TEXT,       -- e.g. "****5678"
  currency_code VARCHAR(3) REFERENCES admin.currencies(currency_code),
  account_type TEXT CHECK (account_type IN ('checking','savings','merchant')),
  is_default BOOLEAN DEFAULT FALSE,
  is_active BOOLEAN DEFAULT TRUE,
  notes TEXT,
  created_by UUID REFERENCES admin.admin_users(id),
  updated_by UUID REFERENCES admin.admin_users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
```
