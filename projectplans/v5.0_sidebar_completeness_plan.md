# Sidebar Completeness & Missing Features — Full Implementation Plan

**Version:** 5.1
**Created:** 2026-06-20
**Updated:** 2026-06-20
**Status:** Complete
**Scope:** Add sidebar entries for 4 existing unreachable modules, add missing pages for existing routes, add high-value new features (Notifications, Email Templates, API/Webhooks, Reports, Billing/Invoicing, Localization)

---

## Context

The admin panel has 4 fully built modules (Security, Content, Feedback, Mirrors) with pages and routes wired in `shellRoutes.jsx` but **zero sidebar entries** — they are completely unreachable via navigation. Additionally, the Admin Management module has 2 pages (Role Permissions, Active Sessions) and Support has 1 page (Announcements) with routes defined but no sidebar links. Beyond fixing these gaps, several high-value features common in enterprise admin panels (Stripe, Salesforce, Jira, Firebase) are missing entirely.

---

| subject_template | TEXT | Email subject (supports `{{variables}}`) |

| category | TEXT NOT NULL | e.g., `billing`, `security`, `system`, `support` |
| is_active | BOOLEAN DEFAULT TRUE | |

| created_at / updated_at | TIMESTAMPTZ | |

**`admin.notifications`**

| Column | Type | Notes |
|---|---|---|

- `get_notification_count(admin_id)` → INTEGER
- `dismiss_notification(notification_id, admin_id)` → BOOLEAN
- CRUD for notification_templates and alert_rules

**Frontend:**

- **Notification dropdown/panel** — list of recent notifications, mark read, click to navigate
- **NotificationSettingsPage** — manage templates, configure alert rules
- **AlertRulesPage** — CRUD for alert rules with condition builder
