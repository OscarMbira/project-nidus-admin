**Status:** Complete  
**Created:** 2026-07-01  
**Feature:** End-to-end Affiliate Program — admin management panel, commission tracking, and fully functional affiliate landing pages on both Platform (`/platform?ref=CODE`) and Simulator (`/simulator?ref=CODE`).

---

## Overview

The affiliate program allows external partners (trainers, coaches, institutions, individuals) to earn commissions by referring paying customers to Nidus. The feature spans three codebases:

| Layer | Location | Purpose |
|-------|----------|---------|
| Admin panel | `project-nidus-admin` | Manage affiliates, view stats, approve commissions, manage payouts |
| Platform landing | `project-nidus` (`/platform`) | Capture `?ref=CODE`, track clicks, show affiliate join page |
| Simulator landing | `project-nidus` (`/simulator`) | Same for Simulator-specific funnel |

---

## Affiliate Link Mechanics

```
Affiliate gets:  https://app.nidus.com/platform?ref=JOHNCOACH
                 https://app.nidus.com/simulator?ref=JOHNCOACH

Visitor clicks → ?ref= captured in URL
              → stored in localStorage (30-day TTL)
              → click event written to platform DB
              → visitor browses, signs up, subscribes
              → conversion recorded with affiliate_code
              → admin reviews, approves commission, marks paid
```

### 1.1 — Tables

#### `admin.affiliates`

```sql
CREATE TABLE admin.affiliates (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code TEXT UNIQUE NOT NULL,           -- e.g. 'JOHNCOACH2024'
    name TEXT NOT NULL,
    email TEXT NOT NULL,
    phone TEXT,
    website TEXT,
    target_system TEXT NOT NULL DEFAULT 'both'
        CHECK (target_system IN ('platform', 'simulator', 'both')),
    commission_rate_pct NUMERIC(5,2) NOT NULL DEFAULT 10.00
        CHECK (commission_rate_pct >= 0 AND commission_rate_pct <= 100),
    status TEXT NOT NULL DEFAULT 'pending'
        CHECK (status IN ('pending', 'active', 'suspended', 'terminated')),
    application_notes TEXT,             -- from the landing page form
    payout_method TEXT DEFAULT 'bank_transfer'
        CHECK (payout_method IN ('bank_transfer', 'paypal', 'other')),
    payout_details JSONB DEFAULT '{}',  -- encrypted/masked in UI
    approved_by UUID REFERENCES admin.admin_users(id),
    approved_at TIMESTAMPTZ,
    created_by UUID REFERENCES admin.admin_users(id),  -- NULL = self-applied
    updated_by UUID REFERENCES admin.admin_users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

#### `admin.affiliate_payouts`

Tracks commission periods (manual or monthly batch):

```sql
CREATE TABLE admin.affiliate_payouts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    affiliate_id UUID NOT NULL REFERENCES admin.affiliates(id),
    period_start DATE NOT NULL,
    period_end DATE NOT NULL,
    total_clicks INTEGER NOT NULL DEFAULT 0,
    total_conversions INTEGER NOT NULL DEFAULT 0,
    gross_revenue NUMERIC(12,2) NOT NULL DEFAULT 0,
    commission_rate_applied NUMERIC(5,2) NOT NULL,
    commission_amount NUMERIC(12,2) NOT NULL DEFAULT 0,
    currency VARCHAR(3) NOT NULL DEFAULT 'USD',
    status TEXT NOT NULL DEFAULT 'pending'
        CHECK (status IN ('pending', 'approved', 'paid', 'cancelled')),
    notes TEXT,
    approved_by UUID REFERENCES admin.admin_users(id),
    approved_at TIMESTAMPTZ,
    paid_at TIMESTAMPTZ,
    created_by UUID REFERENCES admin.admin_users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

Indexes, triggers (`set_updated_at`), and RLS policies follow the same pattern as other admin tables.

### 1.2 — RPCs

#### `create_affiliate(name, email, code, commission_rate, target_system, notes, admin_user_id)` — admin-side create

Validates code uniqueness, sets status `active`.

#### `apply_as_affiliate(name, email, phone, website, target_system, notes)` — public RPC (anon)

Called from landing page affiliate signup form. Sets status `pending`. Grants `EXECUTE` to `anon` role.

#### `update_affiliate(affiliate_id, data, admin_user_id)`

Updates name, commission rate, payout details, target_system.

#### `approve_affiliate(affiliate_id, admin_user_id)`

Sets `status = 'active'`, records `approved_by`, `approved_at`. Restricted to `affiliate:approve` permission.

#### `suspend_affiliate(affiliate_id, reason, admin_user_id)`

Sets `status = 'suspended'`. Restricted to `super_admin`.

#### `terminate_affiliate(affiliate_id, admin_user_id)`

Sets `status = 'terminated'`. Restricted to `super_admin`.

#### `regenerate_affiliate_code(affiliate_id, admin_user_id)`

Generates a new unique code. Restricted to `super_admin`.

#### `create_affiliate_payout(affiliate_id, period_start, period_end, commission_amount, gross_revenue, currency, admin_user_id)`

Creates a payout record in `pending` state.

#### `approve_affiliate_payout(payout_id, admin_user_id)`

Sets `status = 'approved'`. Restricted to `affiliate:payout_approve` (`super_admin` only).

#### `mark_affiliate_payout_paid(payout_id, admin_user_id)`

Sets `status = 'paid'`, `paid_at = NOW()`.

### 2.1 — Tables

#### `public.affiliate_clicks`

```sql
CREATE TABLE public.affiliate_clicks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    affiliate_code TEXT NOT NULL,
    target_system TEXT NOT NULL CHECK (target_system IN ('platform', 'simulator', 'both')),
    referral_url TEXT,
    landing_path TEXT,
    ip_hash TEXT,                 -- SHA-256 of IP, not raw IP (privacy)
    user_agent_hash TEXT,
    session_id TEXT,              -- random, for click-to-conversion linking
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_affiliate_clicks_code ON public.affiliate_clicks (affiliate_code);
CREATE INDEX idx_affiliate_clicks_created ON public.affiliate_clicks (created_at DESC);
```

#### `public.affiliate_conversions`

```sql
CREATE TABLE public.affiliate_conversions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    affiliate_code TEXT NOT NULL,
    click_id UUID REFERENCES public.affiliate_clicks(id),
    user_id UUID REFERENCES auth.users(id),
    target_system TEXT NOT NULL CHECK (target_system IN ('platform', 'simulator')),
    conversion_type TEXT NOT NULL CHECK (conversion_type IN ('signup', 'subscription', 'upgrade')),
    subscription_id UUID,
    gross_amount NUMERIC(12,2),
    currency VARCHAR(3) DEFAULT 'USD',
    commission_amount NUMERIC(12,2),
    commission_rate_pct NUMERIC(5,2),
    credited_to_payout_id UUID,  -- set when admin creates payout
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_affiliate_conversions_code ON public.affiliate_conversions (affiliate_code);
CREATE INDEX idx_affiliate_conversions_user ON public.affiliate_conversions (user_id);
```

RLS: `SELECT` to `authenticated` (their own rows). `INSERT` via `SECURITY DEFINER` RPC.

#### Public RPCs in platform DB

`track_affiliate_click(p_code, p_target_system, p_referral_url, p_landing_path, p_session_id)` — `GRANT EXECUTE TO anon`.

Returns `click_id` UUID for linking to later conversion.

`record_affiliate_conversion(p_affiliate_code, p_click_id, p_user_id, p_target_system, p_conversion_type, p_subscription_id, p_gross_amount, p_currency)` — called on successful signup/subscription. Returns `conversion_id`.
