**Version:** 4.2

---

## Context

The admin panel previously used a hardcoded list of 8 currencies in `packages/shared/src/subscriptionConstants.js`. Currency columns exist on `platform_subscriptions`, `simulator_subscriptions`, `payment_transactions`, `subscription_plans`, and `pricing_change_history` — but there was no admin-managed currency table, no exchange rate system, and analytics pages hardcoded 'USD'. Admins can now manage allowed currencies, maintain exchange rates with history, and have proper multi-currency reporting across all three systems.

### Cross-System Coverage

| System | Schema | Tables Using Currency |
|---|---|---|
| **Platform** | public | `platform_subscriptions`, `payment_transactions`, `subscription_plans` |
| **Simulator** | sim | `simulator_subscriptions` |
| **Admin** | admin | `pricing_change_history`, `currencies`, `exchange_rates`, `countries` |
